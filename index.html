O que é o Git?

O Git funciona como um sistema de segurança e colaboração para o desenvolvimento de software. Ele monitora arquivos e gerencia o histórico de alterações através de uma estrutura lógica simples.

Git x GitHub

Git:

Como antes dito acima, o Git funciona como um sistema de segurança e colaboração para o desenvolvimento de software. Ele monitora arquivos e gerencia o histórico de alterações através de uma estrutura lógica simples.

GitHub:

Já o GitHub, é uma plataforma baseada na nuvem que hospeda códigos-fonte e arquivos de projetos, utilizando o sistema de controle de versão Git.

Ligação entre os dois:

O Git é aquela nossa memória impecável que lembra de cada detalhe e não nos deixa esquecer onde errámos no código. Já o GitHub é a mesa de café na nuvem: o lugar perfeito para guardar os planos, chamar os amigos e construir algo incrível juntos.

Como instalar o Git?

Pode parecer simples, mas é sempre bom lembrar como instalar o bom e velho Git!

Instalar:

Para instalar o Git é muito simples, basta você acessar o site oficial do Git Downloads, e o próprio irá detectar seu sistema operacional de forma automática.
